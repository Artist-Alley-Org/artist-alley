# ABR (Adobe Photoshop Brush) parser

Parses Photoshop `.abr` brush packs into a stream of brush stamps + a
descriptor block. We use this to import user-supplied brush packs
and to extract the bitmaps + parameters that drive our stamp-based
brush renderer (Phase 1.21).

## Source

`abr.ksy` is vendored from
[jlai/brush-viewer](https://github.com/jlai/brush-viewer/blob/main/shared/abr/ABR.ksy)
(MIT licensed, attribution preserved). It covers ABR format
versions 6.1 and 6.2 — the "modern" PSD-style format used by every
Photoshop release since CS5. Older v1/v2 ABRs are out of scope
(those packs are increasingly rare; users importing legacy packs
can re-export from Photoshop CC).

## Regenerating the Go parser

The Go code in this package is generated by the Kaitai Struct
compiler from `abr.ksy`. Don't edit the generated file by hand —
re-run the compiler instead.

```bash
# Install ksc (one-off; the .deb is also fine):
curl -sSL -o /tmp/ksc.zip https://github.com/kaitai-io/kaitai_struct_compiler/releases/download/0.10/kaitai-struct-compiler-0.10.zip
unzip -q /tmp/ksc.zip -d /tmp/

# Regenerate:
/tmp/kaitai-struct-compiler-0.10/bin/kaitai-struct-compiler \
    --target go \
    --outdir app/internal/abr \
    app/internal/abr/abr.ksy
```

The compiler emits `Abr.go`. We add a thin hand-written `parse.go`
wrapper that exposes a friendlier API + handles bitmap
decompression (PackBits RLE — not part of the .ksy spec).
