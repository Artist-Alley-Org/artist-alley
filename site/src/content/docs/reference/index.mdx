## Regenerating

Reference pages regenerate on every site build. To preview locally:

```bash
cd site
pnpm install
pnpm dev
```

The `prebuild` step in `site/package.json` runs:

1. `scripts/sync-adrs.mjs` — copies `docs/adr/*.md` into the docs
   collection with frontmatter inferred from each file's h1.
2. `scripts/sync-openapi.mjs` — copies `app/api/openapi.yaml` to
   `public/openapi.yaml` so the `starlight-openapi` plugin can read it.
3. `scripts/generate-schema-docs.mjs` — parses `app/schema.sql` and
   emits a single `reference/schema.mdx` page.
