The principles guiding the artist experience are described in the
[design pillars](/whitepaper/pillars/#1-artist-first-not-archive-first).

What we're aiming for:

- Drag a folder onto the page → assets uploaded, metadata inferred.
- One screen per asset, scrollable, comments thread inline.
- Versioning is implicit: re-upload to the same asset slot to create
  a new version; old versions remain reachable.
- Notifications when a reviewer leaves feedback on your work.
