A single view of what's been built, what's in flight, and what's moving on
the repo right now. Combines the structured roadmap with live(-ish) GitHub
snapshots.

<EngineeringDashboard />

## How this is wired

- **Roadmap data** comes from a hand-authored
  [`src/content/roadmap/roadmap.json`](https://github.com/mscrnt/artist-alley/blob/main/site/src/content/roadmap/roadmap.json),
  validated by a Zod schema in
  [`src/content.config.ts`](https://github.com/mscrnt/artist-alley/blob/main/site/src/content.config.ts).
  The narrative version at [`docs/roadmap.md`](https://github.com/mscrnt/artist-alley/blob/main/docs/roadmap.md)
  remains the canonical prose.
- **GitHub snapshot** comes from
  [`src/content/github/snapshot.json`](https://github.com/mscrnt/artist-alley/blob/main/site/src/content/github/snapshot.json),
  refreshed on a cron by a scheduled GitHub Actions workflow. Local devs can
  run `pnpm refresh-github` (with `gh.exe` authed) to update against the
  live API for testing.

Run locally:

```bash
cd site
pnpm install
pnpm refresh-github    # optional — uses gh.exe to fetch a fresh snapshot
pnpm dev               # http://localhost:4321/engineering/
```
